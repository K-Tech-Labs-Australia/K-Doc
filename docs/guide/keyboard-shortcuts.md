# Keyboard shortcuts

This page lists every K-Doc command that has a shortcut out of the box, grouped the way the command palette groups them. The shortcuts shown are those of the **Word** preset, which K-Doc uses unless you choose another.

## Find a shortcut in K-Doc

- **Help → Keyboard Shortcuts** lists every command that can have a shortcut, with the keys in effect now. You can search it by command name or by key, and change shortcuts there. See [Customising K-Doc](customising.md#change-a-shortcut).
- The command palette (`Ctrl+Shift+P`) lists every command, and shows each one's shortcut beside it. Type part of a command's name to find it and press `Enter` to run it.
- Menus show each command's shortcut on the right.

If you choose another preset or change a shortcut, the menus, the palette, and the ribbon's tooltips show your keys instead of the ones on this page.

Where a command has two shortcuts, either one works.

## Fixed keys

Some keys are not part of any preset and cannot be changed:

- `Tab` and `Shift+Tab` change a list item's level in a list, and move between cells in a table.
- `Ctrl+Shift+V` pastes as plain text.
- `Alt+Shift+Right` and `Alt+Shift+Left` widen and narrow a selected picture.

## Word shortcuts K-Doc does not use

Some Word shortcuts have no meaning in Markdown. With the Word preset, pressing one shows a short explanation in the status bar instead of doing nothing:

| Shortcut | Why it does nothing |
| :--- | :--- |
| `Ctrl+U` | Markdown has no underline. Use bold or italic instead. |
| `Ctrl+J` | Markdown has no justified text. |
| `Ctrl+1`, `Ctrl+2`, `Ctrl+5` | Markdown has no line spacing. Set the spacing K-Doc shows with **Line height** in **Settings → Appearance**. |

## Where shortcuts work

Formatting and insert shortcuts, such as `Ctrl+B` and `Ctrl+K`, work while the K-Doc view of the document has the focus. Undo, Redo, Paste Special, Image…, Go Back, and Go Forward work anywhere except while you are typing in a text box, such as the find bar. The rest, such as `Ctrl+S` and `Ctrl+Shift+P`, work anywhere in the K-Doc window.
