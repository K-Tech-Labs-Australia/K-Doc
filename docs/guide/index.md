# K-Doc user guide

K-Doc is a word processor for Markdown files. You write in a formatted view, much as you would in Word, while the file on disk stays plain, portable Markdown that any other tool can read. Anything you did not edit is saved back exactly as it was.

This guide explains how to do things in K-Doc. Open it at any time with **Help → User Guide** or `F1`; inside K-Doc it opens locked, so you can read it without changing it by accident.

## Where to start

- New to K-Doc? Read [Getting started](getting-started.md): installing, opening and saving files, the three views, tabs and windows, and how K-Doc keeps your work safe.
- Want to find a command? Press `Ctrl+Shift+P` for the command palette. It lists every command with its shortcut, and you can search it.

## The three views

K-Doc shows each document in one of three views. Switch with the buttons in the title bar, the **View** menu, or `Ctrl+/`.

| View | What you see |
| --- | --- |
| **K-Doc** | The formatted document. You edit it directly, as in a word processor. |
| **Source** | The Markdown text itself. |
| **Split** | Both side by side. They share one undo history, whichever side you type in. |
