# Rich Inline Constructs

A ==highlighted phrase== sits in ordinary prose.

Water is H~2~O and the area of a circle is pi r^2^.

A highlight can contain ==**strong emphasis** and _emphasis_== across siblings.

Nesting works: ==a phrase with x^n^ inside it== stays one highlight.

Strikethrough is unaffected: ~~removed~~ next to H~2~O.

Escapes are honoured: \==this is not a highlight\== and a lone \~tilde.

Inline code is skipped entirely: `==not a highlight==` and `x~1~`.
